# Правила проекта генератора карточек СИЗ

## Единственный источник норм

Файл `data/norms.xlsx` является единственным источником сведений о положенных СИЗ.

Запрещено использовать для определения положенных СИЗ:

- штатное расписание;
- перечни должностей;
- кадровые выгрузки;
- файл `positions.xlsx`;
- прежний скрипт `check_positions.py`;
- автоматически рассчитанные или предполагаемые соответствия должностей.

## Правило определения СИЗ

Если пара `Подразделение + Должность` присутствует в `data/norms.xlsx`, программа использует только перечисленные для неё СИЗ.

Если пары нет в `data/norms.xlsx`, карточка не создаётся и СИЗ не назначаются.

Отсутствие должности в нормах не является ошибкой данных. Это означает, что в действующих утверждённых нормах для неё не предусмотрены СИЗ.

## Изменение норм

Не изменять `data/norms.xlsx` без прямого указания пользователя.

Перед изменением норм необходимо:

1. создать резервную копию;
2. проверить структуру файла;
3. проверить SHA-256 до и после;
4. протестировать создание карточек;
5. зафиксировать изменение отдельным коммитом.

## Заявки

Заявка на добавление должности:

- сохраняется отдельно в папке `requests`;
- не изменяет нормы автоматически;
- не является основанием для автоматического назначения СИЗ.

## Запрещённые действия

Не допускается:

- самостоятельно подбирать СИЗ;
- переносить СИЗ с похожей должности;
- сопоставлять должности по названию, разряду или категории;
- создавать нормы по штатному расписанию;
- восстанавливать удалённую логику сравнения со штаткой;
- создавать отчёты `positions_check.xlsx`.

## Проверка программы

Основные проверки:

- запуск: `python app.py`;
- запуск через `run_app.bat`;
- загрузка подразделений и должностей только из `data/norms.xlsx`;
- создание карточки для существующей пары;
- отказ в создании карточки для отсутствующей пары;
- неизменность `data/norms.xlsx` после работы программы.
