# Генератор личных карточек учета выдачи СИЗ

Минимальный Python-проект для формирования Excel-файлов личных карточек учета выдачи СИЗ.

Проект:

- читает `data/norms.xlsx` с нормами выдачи;
- читает `data/employees.xlsx` с работниками;
- ищет нормы по паре `Подразделение + Должность`;
- создает отдельную карточку Excel для каждого найденного работника;
- сохраняет результат в папку `output`;
- записывает ненайденные должности или подразделения в `output/warnings.xlsx`.

В проекте есть простой графический интерфейс на `tkinter`, а основная логика вынесена в функции, которые можно вызывать из кода.

## Важно про примерные данные

Файлы-заглушки содержат только учебные строки. Они нужны, чтобы проверить работу программы, и не являются реальными нормами СИЗ. Перед использованием замените `data/norms.xlsx` на утвержденные нормы вашей организации.

Рабочие файлы лежат в папке `data`. Учебные файлы лежат отдельно в папке `sample_data`.

Папка `sample_data` нужна только для тестов и обучения. Файлы из нее не используются автоматически при запуске программы.

## Проверка справочника должностей

Файл `data/positions.xlsx` используется как контрольный справочник подразделений и должностей. Он нужен, чтобы сверять штатное расписание с файлом норм `data/norms.xlsx`.

Обязательные колонки `data/positions.xlsx`:

- `Подразделение`
- `Должность`
- `СИЗ предусмотрены`
- `Комментарий`

Если файла `data/positions.xlsx` нет, скрипт создаст учебную заглушку с правильными колонками.

Запуск проверки:

```bash
py check_positions.py
```

После запуска создается отчет:

```text
output/positions_check.xlsx
```

В отчете есть пять листов:

- `Есть в штатке и в нормах` — пары `Подразделение + Должность`, которые есть и в `positions.xlsx`, и в `norms.xlsx`;
- `Есть в штатке, нет в нормах` — пары из штатного расписания, которых нет в нормах. Это не всегда ошибка: возможно, по этим должностям СИЗ не предусмотрены;
- `Есть в нормах, нет в штатке` — пары из норм, которых нет в штатном расписании. Это может означать устаревшую должность или расхождение в названии;
- `Возможные совпадения` — похожие пары из двух списков расхождений с процентом сходства подразделений и должностей;
- `Совпадения по разрядам` — случаи, когда в штатном расписании разряд или категория указаны отдельной должностью, а в нормах несколько разрядов или категорий объединены в одну строку.

Лист `Возможные совпадения` является справочным. Он помогает заметить возможное переименование или различие в написании, но ничего автоматически не исправляет в `data/positions.xlsx` и `data/norms.xlsx`.

Лист `Совпадения по разрядам` также является справочным. Например, должность `Инженер по метрологии 1 категории` может считаться условно покрытой групповой нормой `Инженер по метрологии 1, 2 категории`. Такие найденные должности не включаются в лист `Есть в штатке, нет в нормах`.

Сравнение выполняется без учета регистра и лишних пробелов в начале и конце значения. Исходные значения в файлах не изменяются.

## Запуск

Пакетная генерация по файлам `data/norms.xlsx` и `data/employees.xlsx`:

```bash
python main.py
```

После запуска файлы появятся в папке `output`.

Графический интерфейс:

```bash
python app.py
```

На Windows интерфейс также можно запустить двойным кликом по файлу:

```bash
run_app.bat
```

GUI использует файл `data/norms.xlsx` для списков подразделений и должностей. Готовые карточки сохраняются в папку `output`.

Готовая карточка создается с двумя листами:

- `Лицевая сторона` — сведения о работнике, размеры и таблица положенных СИЗ;
- `Оборотная сторона` — таблица учета фактической выдачи и возврата СИЗ.

Шаблон `templates/card_template.xlsx` приведен к печатному виду файла `reference/Карточка СИЗ.xlsx` по Приказу Минтруда № 766н. Лист `Лицевая сторона` создан по листу `стр.1` образца, а лист `Оборотная сторона` создан по листу `стр.2`.

Оба листа настроены для печати в книжной ориентации и помещаются по ширине на одну страницу.

## Подготовка к сборке exe

В будущем проект можно будет собрать в Windows-приложение с помощью PyInstaller.
На этом этапе exe-файл не собирается.

Установка PyInstaller:

```bash
py -m pip install pyinstaller
```

Пример команды сборки:

```bash
py -m PyInstaller --onefile --windowed --name SIZCardGenerator app.py
```

Рядом с готовым exe должны лежать рабочие папки проекта:

- `data`
- `templates`
- `output`
- `reference`, если используется файл-образец

Рабочий файл норм должен находиться рядом с exe по пути:

```text
data/norms.xlsx
```

Папка `templates` должна содержать шаблон карточки:

```text
templates/card_template.xlsx
```

В готовой карточке также есть поля для фактической выдачи СИЗ:

- `Дата выдачи`
- `Количество выдано`
- `Лично / карточка`
- `Подпись получившего СИЗ`
- `Дата возврата`
- `Количество возвращено`
- `Подпись сдавшего СИЗ`
- `Акт списания, дата и номер`

Эти поля добавляются в карточку, но автоматически не заполняются. Программа заполняет в нижней таблице только `Наименование СИЗ`, а данные фактической выдачи и возврата вносятся вручную.

## Как работает поиск норм

Программа сравнивает подразделение и должность без учета регистра и лишних пробелов.

Например, работник из `data/employees.xlsx` получит нормы только если в `data/norms.xlsx` есть строка с тем же подразделением и той же должностью.

Если совпадение не найдено, карточка для такого работника не создается, а запись попадает в `output/warnings.xlsx`.
